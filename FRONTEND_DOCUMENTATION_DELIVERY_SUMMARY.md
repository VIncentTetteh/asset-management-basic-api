## 💡 KEY INFORMATION

### API Base URL
```
http://localhost:8085/api/v1
```

### Authentication
- Type: JWT Bearer Token
- Header: `Authorization: Bearer {token}`
- Token Expiry: 1 hour
- Auto-refresh: Yes (handled by axios interceptor)

### HTTP Status Codes
- 200: OK (GET, PATCH, PUT)
- 201: Created (POST)
- 202: Accepted (async operations)
- 204: No Content (DELETE)
- 400: Bad Request (validation error)
- 401: Unauthorized (auth failure)
- 403: Forbidden (permission)
- 404: Not Found
- 409: Conflict (state issue)
- 422: Unprocessable Entity (business logic)
- 500: Server Error

### Rate Limits
- Login: 5 requests per 5 minutes
- General: 100 requests per minute

### Pagination
```
GET /assets?page=0&size=20&sort=createdAt,desc
```
