## 🚀 Quick Start (5 Steps)

### Step 1: Setup Database (5 min)
```sql
CREATE DATABASE asset_management;
CREATE USER asset_user WITH PASSWORD 'password';
GRANT ALL ON DATABASE asset_management TO asset_user;
```

### Step 2: Configure Environment (5 min)
Set database URL, username, password in application.properties

### Step 3: Build Project (10 min)
```bash
mvn clean install -DskipTests
```

### Step 4: Run Application (5 min)
```bash
mvn spring-boot:run
```

### Step 5: Test API (5 min)
```bash
curl http://localhost:8080/api/v1/organisations
```

**Total: 30 minutes to production-ready system**
